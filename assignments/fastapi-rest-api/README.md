# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Build a REST API for managing tasks with FastAPI. Practice defining request models, handling CRUD operations, and returning appropriate HTTP status codes.

## 📝 Tasks

### 🛠️ Run a FastAPI Application

#### Description
Set up the provided FastAPI application and explore the interactive API documentation generated by the framework.

#### Requirements
Completed program should:

- Install FastAPI and Uvicorn with `python -m pip install fastapi uvicorn`
- Start the application with `uvicorn main:app --reload`
- Open `http://127.0.0.1:8000/docs` and confirm the API documentation loads
- Return a JSON message from the root endpoint (`/`)


### 🛠️ Model and Retrieve Tasks

#### Description
Represent tasks with Pydantic models and add endpoints for listing tasks and retrieving one task by its ID. Store tasks in memory; a database is not required.

#### Requirements
Completed program should:

- Define a task input model with a title and a `completed` field that defaults to `False`
- Define a task response model that also includes an integer `id`
- Implement `GET /tasks` to return all tasks
- Implement `GET /tasks/{task_id}` to return one task or HTTP `404` when it does not exist


### 🛠️ Create, Update, and Delete Tasks

#### Description
Complete the task API by adding endpoints to create a task, replace an existing task, and delete a task.

#### Requirements
Completed program should:

- Implement `POST /tasks` to create a task with a unique ID and return HTTP `201`
- Implement `PUT /tasks/{task_id}` to update a task or return HTTP `404` when it does not exist
- Implement `DELETE /tasks/{task_id}` to remove a task and return HTTP `204`, or HTTP `404` when it does not exist
- Validate request data with Pydantic and verify each endpoint using `/docs`
