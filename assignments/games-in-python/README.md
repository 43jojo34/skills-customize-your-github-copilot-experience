
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a word-guessing game in Python to practice string manipulation, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Set Up the Game

#### Description
Create the initial game state by selecting a hidden word and showing the player their progress as they guess its letters.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses from the player
- Show correctly guessed letters and unrevealed letters (for example, `_ _ _`)


### 🛠️ Track Guesses and End the Game

#### Description
Track incorrect guesses and finish the game when the player guesses the word or runs out of attempts.

#### Requirements
Completed program should:

- Track and display the number of incorrect guesses remaining
- End when the word is guessed or the player runs out of attempts
- Display a win or loss message that matches the game outcome
